# 第4章 · 教学型 B+ 树索引

> 对应源码：`src/btree_mgr.c`、`src/btree_mgr.h`

## 4.1 文件布局

第0页保存索引元数据：key 类型、阶数、根页、节点数和条目数。其余页面保存内部节点或叶节点。叶节点通过 next 指针相连，因此可以按 key 顺序范围扫描。

## 4.2 已实现能力

- 创建、打开、关闭和删除索引文件；
- INT、FLOAT、BOOL 和固定上限字符串 key；
- 点查、插入、节点分裂；
- 顺序扫描；
- 重复 key 拒绝；
- 删除叶节点中的 key。

## 4.3 有意保留的教学简化

删除只在叶节点内左移条目，**不执行借位、合并、父分隔键调整或根收缩**。因此这是支持基本删除行为的教学型 B+树，而不是完整的生产级 B+树删除算法。大量删除后节点可能低利用率，但现有点查和叶链扫描仍保持可用。

字符串 key 在索引内使用固定长度上限。项目也没有并发锁、页校验、WAL或崩溃恢复。

## 4.4 验证

```bash
make
./build/test_btree
```

测试覆盖正序/逆序插入、分裂、点查、范围扫描、重复 key 和简化删除。

进阶练习：为删除补充 underflow 检测、兄弟借位、节点合并、父节点递归修复和根收缩。
